# Evaluators code and prompts

Notebooks and prompts for Learning Commons evaluators.

To set up your environment and run a notebook, follow the [Python notebooks quickstart](https://docs.learningcommons.org/evaluators/getting-started/quickstart#python-notebooks).

For the list of evaluator families, see the [evaluators introduction](https://docs.learningcommons.org/evaluators/understanding-evaluators/introduction).
