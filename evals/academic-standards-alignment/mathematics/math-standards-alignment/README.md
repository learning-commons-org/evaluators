# [Math Standards Alignment](https://docs.learningcommons.org/evaluators/academic-standards-evaluators/math-standards-alignment)

Evaluates whether an assessment question aligns to a math standard by checking alignment against each of the standard's learning components.

- Schemas: [input](./input_schema.json), [output](./output_schema.json)
- [Python notebook](./example_notebook.ipynb)
- Prompts: [`system.txt`](./system.txt), [`user.txt`](./user.txt)
- Model used: Claude Haiku 4 (`claude-haiku-4-5-20251001`) with temperature of 0 (fixed)
