# Graphics Accuracy

Evaluates whether a math visual (plot, chart, equation, diagram, worked solution, or word problem) correctly shows what its specification states — a claim about the image, or a question with its expected answer. Built for AI-generated content: the text is trusted, the image is under review. Early access; docs page pending.

- Schemas: [input](./input_schema.json), [output](./output_schema.json)
- [Fixtures](./fixtures.json), images in [`images/`](./images/)
- Prompts: [`system.txt`](./system.txt), [`user.txt`](./user.txt)

Validated on competition mathematics (MathVision); no per-grade measurement exists yet. No notebook yet.
