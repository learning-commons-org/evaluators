# Graphics Accuracy

Checks whether a math visual (plot, chart, equation, diagram, worked solution, or word problem) correctly shows what its specification states — a claim about the image, or a question with its expected answer. Built for AI-generated content: the text is trusted, the image is under review. Early access.

- Schemas: [input](./input_schema.json), [output](./output_schema.json)
- Prompts: [`system.txt`](./system.txt), [`user.txt`](./user.txt)

Family and tag are not yet decided; this evaluator lives under `tbd/tbd` until they are. No fixtures or notebook yet: fixtures for an image evaluator carry image bytes, and the format for that is still to be settled.
