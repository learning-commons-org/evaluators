## Bundled third-party data

Two modules under `src/features/flesch-kincaid/data/` contain data copied from third-party
sources, so that the Flesch-Kincaid score matches Python `textstat` exactly. They are
generated by `scripts/generate-flesch-kincaid-data.py` and each carries this attribution in
its own header.

### CMU Pronouncing Dictionary — `data/syllables.ts`

Syllable counts derived from the Carnegie Mellon University Pronouncing Dictionary
(CMUdict), obtained via the [NLTK](https://www.nltk.org/) corpus of the same name, which is
the source `textstat` itself uses. CMUdict is distributed under a BSD-style licence
permitting redistribution and use, including commercially, with attribution. Only the
syllable count per word is retained; the pronunciations themselves are not included.

- Upstream: <http://www.speech.cs.cmu.edu/cgi-bin/cmudict>

### LibreOffice English hyphenation patterns — `data/hyphenation-patterns.ts`

The contents of `hyph_en_US.dic`, copied verbatim from
[pyphen](https://pypi.org/project/pyphen/), which takes its dictionaries from the
[LibreOffice dictionaries repository](https://git.libreoffice.org/dictionaries). `textstat`
uses these patterns for words CMUdict does not carry, so reproducing its score requires
them.

Those dictionaries are distributed under a **GPL 2.0+ / LGPL 2.1+ / MPL 1.1 tri-licence**.
This SDK uses them under the **MPL 1.1** option. MPL 1.1 is file-level copyleft: the module
containing the patterns remains MPL 1.1 and its notice must be preserved, while the rest of
this SDK remains MIT. Redistributors must keep that notice and make the file's source
available, which it is, in this repository.

- MPL 1.1: <https://www.mozilla.org/media/MPL/1.1/index.txt>

If this arrangement is not acceptable for a given distribution, the patterns module can be
removed; `docs/flesch-kincaid.md` records what that costs in accuracy.
